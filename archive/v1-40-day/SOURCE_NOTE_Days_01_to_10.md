## What each day folder contains

- **Deck** (.pptx): the session slides.
- **Pre-read** (PDF): a short, non-technical read for before class.
- **Post-read** (PDF): recap of the day plus topics that go further.
- **Colab notebook** (.ipynb): live demos. Option A cells run in Google Colab; Option B cells (commented) are for VS Code.
- **App build prompts** (.md): prompts for building the day's app with an AI coding assistant.
- **Hands-on problem statements** (PDF): practice problems from warm-up to stretch.
- **Workbook** (.docx): fill in the blanks, short answers, predict the output and write code. Type in Word or Google Docs, or print.
- **Quiz** (.txt): 15 questions on the previous day, in CSV rows ready to paste into the quiz tool. Day 1 has no quiz.

The `Day11` folder holds only the quiz on Day 10, ready for the start of Day 11.

## Running the notebooks

- **Colab:** upload the .ipynb file and run cells top to bottom.
- **VS Code:** install Python, plus the Python and Jupyter extensions (and Node.js LTS for Days 9 and 10). Open the notebook, comment out Option A and uncomment Option B where shown.
- MongoDB days use `mongomock` in Colab. In VS Code, set `MONGO_URI` to a local MongoDB or a free Atlas cluster.
