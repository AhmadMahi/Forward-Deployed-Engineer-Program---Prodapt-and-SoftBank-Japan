# Days 36 to 40: Capstone

**Dates:** Tue 15 Dec to Mon 21 Dec 2026 | **Code freeze:** Day 39, Fri 18 Dec, 17:00 IST | **Deliverables due:** Day 40, Mon 21 Dec, 09:00 IST

## Notes for trainers

- Starter notebooks run in Colab (Option A) or VS Code (Option B) and in offline demo mode without a key. The default model comes from `LLM_MODEL`; see [docs/MODEL_GUIDE.md](../docs/MODEL_GUIDE.md).
- OpenAI Codex is the AI coding tool. Teams disclose generated code in their README.
- Delete Azure resource groups after Day 40.
- The PDFs and deck are generated by `tools/build/extras/capstone_build.py` from `tools/build/extras/capstone_content.py`. Edit the content file and rebuild rather than editing the PDFs.
