# Day 1 Laptop Pre-Assessment Checklist

**Date:** Mon 26 Oct 2026 | **Time:** 75 minutes in the onboarding block | **Guide:** [Laptop Setup Guide](../shared/Laptop_Setup_Guide.pdf)

Trainer: go through this list with each learner. Mark each row. Anything Required that is not done by the end of Day 1 goes on the follow-up list with an owner and a date.

## Required

| Item | Needed from | Check | Pass |
|---|---|---|---|
| Chrome or Edge, current version | Day 1 | Browser opens Colab | [ ] |
| Google account, Colab works | Day 2 | `print('hello')` runs in a new Colab notebook | [ ] |
| Python 3.12 or newer | Day 2 | `python --version` | [ ] |
| VS Code | Day 3 | `code --version` | [ ] |
| VS Code extensions: Python, Jupyter, OpenAI Codex | Day 3 | Visible in the Extensions panel (Codex sign-in happens on Day 3) | [ ] |
| Git | Day 3 | `git --version`, `git config --global user.name` is set | [ ] |
| GitHub account | Day 3 | Learner can sign in | [ ] |
| Node.js LTS with npm | Day 8 | `node --version`, `npm --version` | [ ] |
| Postman | Day 9 | A GET request returns 200 | [ ] |
| Docker Desktop | Day 20 | `docker run --rm hello-world` | [ ] |
| Can install pip packages | Day 2 | `python -m pip install --upgrade pip` works (proxy and firewall check) | [ ] |

## Laptop basics

| Item | Check | Pass |
|---|---|---|
| Free disk space | At least 20 GB free (Docker images need space) | [ ] |
| Memory | 8 GB minimum, 16 GB recommended for Docker | [ ] |
| Admin rights or IT ticket raised | Learner can install software, or an IT request is open | [ ] |
| Corporate proxy or VPN | Learner can reach colab.research.google.com, pypi.org, registry.npmjs.org, github.com | [ ] |

## Keys and secrets (explain, do not issue yet)

- [ ] Learner knows keys live in Colab Secrets or a git-ignored `.env` file.
- [ ] Learner knows never to paste a key into code, notebooks, prompts, chats or front-end code.
- [ ] Learner knows the Codex key is issued on Day 3 and the app key on Day 12.
