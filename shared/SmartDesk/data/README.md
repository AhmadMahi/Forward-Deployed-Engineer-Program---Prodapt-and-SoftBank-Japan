# SmartDesk sample data

Fictional data for the SmartDesk running project. No real customers or real company policies.

- `tickets.json`: 15 telecom support tickets (id, customer, category, priority, status, body, created_at).
- `telecom_faq.json`: 20 short FAQ entries used by the RAG steps (16, 19, 23 and later).
- `legacy_tickets.csv`: a messy export from the old system, used in steps 13 and 20.
